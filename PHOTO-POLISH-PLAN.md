# Photo and mobile caption polish

Protected refinement pass for `destinations.html`.

## Mobile-first rules
- Captions should be at least 12px on phones with comfortable line-height.
- Caption text must wrap naturally and never be clipped.
- Signature images should remain large enough to understand without opening a separate photo search.
- Myrtos description and caption must remain fully readable beneath the image.
- Preserve the static Villa / Time / Heat / Effort strip and all Maps/photo links.
- Use static HTML/CSS only for guest-critical presentation.

`main` remains unchanged until preview approval.
